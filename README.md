# Gamma vs Linear Image Enhancement

This repository contains a Jupyter Notebook that compares linear brightness/contrast adjustment with gamma correction for image enhancement using OpenCV, NumPy, and Matplotlib.

## Repository Structure

```text
.
├── gamma_linear.ipynb
├── images/
│   ├── blur_moon.jpg
│   ├── chatgpt_edited_image.png
│   ├── dark_blur_moon.jpg
│   └── original.jpg
├── outputs/
├── requirements.txt
├── .gitignore
├── LICENSE
└── README.md
```

## Setup

1. Create and activate a Python virtual environment.
2. Install the project dependencies:

```bash
pip install -r requirements.txt
```

3. Start Jupyter Notebook:

```bash
jupyter notebook
```

4. Open `gamma_linear.ipynb` and run the cells in order.

## Notes

- Input images are stored in `images/`.
- `outputs/` is reserved for generated images or exported results.
- The notebook source logic has been preserved; only image file paths were updated to match the reorganized repository structure.
